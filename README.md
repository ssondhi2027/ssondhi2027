## What I'm building

**[bank-regulatory-platform](https://github.com/ssondhi2027/bank-regulatory-platform)** · [Live app](https://bank-regulatory-platform.netlify.app) · [dbt docs](https://ssondhi2027.github.io/bank-regulatory-platform) · [UI repo](https://github.com/ssondhi2027/Bank-Regulatory-Platform_UI)<br>
A bitemporal data platform that ingests OSFI's Canadian bank regulatory filings (M4/P3/E3, 1996–2026) and Bank of Canada rate data, models them in dbt Core on BigQuery against a BCBS 239-referenced 21-control framework, with GitHub Actions CI/CD, Dagster lineage and Terraform. Served through a responsive React + Vite front end on Netlify and an AWS Lambda (Node 20, ca-central-1) API querying the marts live.

**[Yuktara](https://github.com/ssondhi2027/yuktara)** · [Live app](https://yuktara-health.netlify.app/login)<br>
A workout and diet progress-tracking web app for coaching clients (desktop, tablet and phone), with an admin dashboard for the coach. Netlify front end, FastAPI backend on Render, Supabase Postgres/auth/storage.

**[Analize 360 — Predictive Fleet Analytics](https://github.com/ssondhi2027/Analize-360---Predictive-Fleet-Analytics-For-Commercial-Aviation)**<br>
End-to-end predictive maintenance for commercial aviation on AWS S3, Databricks and Delta Lake: LSTM Remaining-Useful-Life prediction, AOG risk classification 60–90 days ahead, and genetic-algorithm maintenance scheduling targeting 99.5% dispatch reliability.

**[Canada-quality-of-life-Power-BI-dashboard](https://github.com/ssondhi2027/Canada-quality-of-life-Power-BI-dashboard)**<br>
Interactive Power BI dashboard on Statistics Canada data tracking Society, Prosperity, Health, Governance and Environment indicators (2021–2024), with DAX composite indices, synchronized slicers and an executive summary page.

**[Ai-Demand_Planner](https://github.com/ssondhi2027/Ai-Demand_Planner)**<br>
Demand forecasting app comparing ARIMA and XGBoost, with CSV validation, forecast confidence bands, reorder-point/safety-stock calculations and Monte Carlo stockout simulation. FastAPI backend, React + Vite front end.

**[Walmart-Weekly-Sales-Forecasting](https://github.com/ssondhi2027/Walmart-Weekly-Sales-Forecasting)**<br>
Benchmarked Linear Regression, MLP, Random Forest and DNN models (scikit-learn, TensorFlow/Keras) with lag and calendar features — Random Forest won with **R² 0.98**.
